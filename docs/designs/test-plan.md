## Affected Pages/Routes

## Key Interactions to Verify
- Agent asks permission → Notification (allowlisted type) → ring solid, N=1, pill shows it, banner after the 2 s hold
- Hotkey opens the panel on the top item; Return opens it (revision check), Delete dismisses, S snoozes
- Snooze 15 min → item leaves N and ring, banner removed; returns with a banner when the time comes
- `attn setup claude` shows the diff, asks, writes atomically; re-run is a no-op; `--remove` removes only its entries
- `attn doctor` reports each failing check with a fix hint and exits 1
