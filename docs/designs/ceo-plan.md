## Vision

### 10x Check
The one place on a Mac that knows what needs you. Agents, CI and chat feed one attention list; on-device AI sorts unlabelled notifications into "act" or "just so you know" and learns from corrections; Notification Centre becomes an archive nobody opens.

### Platonic Ideal
You never look at Notification Centre. The Dock ring is quiet until something genuinely needs you, then it turns amber and you get one banner (time-sensitive if critical). A pill under the notch says what it is. A hotkey opens the panel on the top item and Return takes you there. Focus holds back everything except critical items. A snoozed item comes back when you said.

## Accepted Scope (added to this plan)
- Claude Code hooks sender with `attn setup claude` (shows the settings.json change, asks, then writes)
- GitHub notifications feed via `gh api notifications` (review_requested, mention, assign; ci_activity only for failed runs), revision = thread updated_at, honouring X-Poll-Interval with If-Modified-Since, clear when the thread leaves the unread list, older unread threads go to Recent quietly on first run, off quietly without gh
- Own banner once per attention episode when the panel isn't open; critical items time-sensitive
- Non-activating floating pill under the notch: top live item, top 3 on hover, hides when idle, can be turned off; rendered in the D12 spike
- User-set global hotkey opening the panel on the top item (Return opens, Delete dismisses, arrows move)
- Snooze 15 min / 1 h / tomorrow 9:00; re-raises unless resolved, expired or dismissed; clock badge in Live
